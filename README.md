# Unigram-Watermark

A Python implementation of **Unigram-Watermark**, a watermark for text generated by large language models, from:

> Xuandong Zhao, Prabhanjan Ananth, Lei Li, Yu-Xiang Wang. *Provable Robust Watermarking for AI-Generated Text.* arXiv:2306.17439 (ICLR 2024).

## How it works

1. **Watermark (Algorithm 1):** a secret key randomly splits the model's vocabulary into a *green list* (a fraction γ of all tokens) and a *red list*. The split is fixed for the whole text. While generating, the logits of green tokens get a bonus δ, so the model picks green tokens a bit more often. The text still reads naturally.
2. **Detect (Algorithm 2):** whoever has the key counts the green tokens in a text and computes a z-score: `z = (|y|_G − γn) / sqrt(nγ(1−γ))`. Human text has about γ·n green tokens (z ≈ 0). Watermarked text has many more. If `z > τ` (τ = 6 in the paper), the text is flagged as watermarked.
3. **Detect "Unique" (Algorithm 4):** the same test, but each distinct token is counted once, with the threshold from Eq. (9). This keeps the false positive rate at a chosen level α, even for repetitive text.

Default parameters match the paper: γ = 0.5, δ = 2.0, nucleus sampling (top-p = 0.9).

## Project structure

```
unigram_watermark/
    core.py         # UnigramWatermark class: green list, Algorithms 1, 2 and 4
    generation.py   # text generation with a Hugging Face model, TPR@FPR, random edits
tests/
    test_core.py    # checks against Theorems 3.1 and 3.7 and the false positive rate
demo.py             # end-to-end experiment with a real language model
```

## Usage

Run the tests (fast, no model download):

```bash
pytest -q
```

Run the demo with a real model (a GPU is recommended; on CPU use fewer prompts):

```bash
python demo.py
python demo.py --num-prompts 5 --max-new-tokens 100           # quicker
python demo.py --model facebook/opt-1.3b --no-chat-template   # a model used in the paper
```

The demo prints detection results and saves `results/z_scores.png` and `results/example_colored.html` (green and red tokens colored as in Table 1 of the paper).

Use it in your own code:

```python
from unigram_watermark import UnigramWatermark, generate

wm = UnigramWatermark(key=42, vocab_size=model.get_output_embeddings().weight.shape[0])
tokens, text = generate(model, tokenizer, "Why is the sky blue?", wm=wm)
print(wm.detect(tokens))         # Algorithm 2
print(wm.detect_unique(tokens))  # Algorithm 4
```

## Notes

- The watermark is added to the logits **before** temperature and top-p, as a Hugging Face logits processor does in `generate()`, which the authors used.
- **Theorem 3.7 (robustness to edits):** its proof (Appendix C.2) uses the statistic `(|y|_G − γn)/√n`, i.e. the z-score *without* the `√(γ(1−γ))` factor of Eq. (2). For the Eq. (2) z-score, the bound has to be divided by `√(γ(1−γ))`. The tests check both forms.
- Not reproduced: paraphrasing attacks (ChatGPT, DIPPER, BART) and the comparison with Kirchenbauer et al. (2023), since they need extra models.
